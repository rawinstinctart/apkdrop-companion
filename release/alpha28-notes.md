# APKDrop Companion Alpha 28

- **Einfacher übernehmen:** Apps aus APKDrop-Links lassen sich mit einem klaren Tipp zur Update-Überwachung hinzufügen.
- **Weniger Ablenkung:** Die wichtigste Aktion steht zuerst; der manuelle Installationsweg bleibt verfügbar.
- **Updates im Blick:** Sobald eine App übernommen wurde, zeigt APKDrop den aktuellen Überwachungsstatus ohne doppelten Bestätigungsbutton.
- **Selbstbestimmt installieren:** APKDrop prüft weiterhin APK-Identität, Dateiintegrität und Signatur. Android fragt vor jeder Installation nach.
