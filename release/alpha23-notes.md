# APKDrop Companion Alpha 23

- **Apps geräteübergreifend merken:** Freiwilliger DropID-Abgleich für gefolgte Entwickler und App-Lesezeichen. Deine Auswahl bleibt auch ohne Sync lokal verfügbar.
- **GitHub Radar vereinfacht:** Neue Release-APKs aus autorisierten Repositories werden verständlich vorgeschlagen. Ein Tipp auf „Entwurf prüfen“ öffnet die private Vorschau; Import und Veröffentlichung bleiben deine Entscheidung.
- **Änderungen auf einen Blick:** Kurze Release-Highlights helfen dir, neue Versionen schneller einzuordnen.
- **Mehr Klarheit bei der Sicherheit:** Neue sensible Berechtigungen und ein Wechsel der APK-Signatur werden hervorgehoben, wenn Vergleichsnachweise vorliegen.
- **Prüfung bleibt lokal:** Cloud-App-Lesezeichen lösen keine Installation aus. APK-Identität, Integrität und Signatur werden vor einer Installation weiterhin auf deinem Gerät geprüft.
