# APKDrop Companion Alpha 11 Preview

**Signed preview, not a production release.** VersionCode 14, Android 8+, original Alpha signing identity and update-compatible package.

- Alpha 9.1: Android 14+ scheduled update monitoring permission and recovery.
- Alpha 10: opt-in DropPilot prepares one verified APK on unmetered Wi-Fi while charging, no silent installer.
- Alpha 11: optional offline encrypted device transfer for saved app pins and developer follows. Requires a user-chosen password and explicit restore confirmation.

CI tests and unsigned build verified; signed APK reconstructed byte-for-byte from the original locally signed artifact, with exact pinned SHA-256 and certificate checked before publishing. GitHub receives only public artifact bytes and a public binary delta, never the keystore.

**Hinweis:** Dies ist eine Preview, keine Produktionsfreigabe oder Play-Protect-Zertifizierung.
